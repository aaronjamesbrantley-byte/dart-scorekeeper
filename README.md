# Dart Score Keeper

A single-file, web-based dart scorer. Click where each dart lands on a standard
board and the score updates automatically. No install, no build — one HTML file.

**Play it:** https://aaronjamesbrantley-byte.github.io/dart-scorekeeper/

## Games
- **X01** (301 / 501 / 701 / 1001) with selectable finish rules: double out,
  master out, straight out, and an optional double-in.
- **Cricket** — Standard, Cut-throat, and No-score variants.
- **Training** — Around the Clock, Count-Up, Shanghai, Bob's 27, and Halve It.

## Features
Clickable dartboard, checkout suggestions, undo, sound, big-screen mode, and
per-device stats/history saved in the browser.

## Run locally
Just open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 4599
```
